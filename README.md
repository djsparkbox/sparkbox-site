# DJ Sparkbox — sparkboxmusic.com

Official press kit website for DJ Sparkbox. Plain HTML, no build step.
Netlify deploys this repository automatically on every push to `main`.

- `index.html` — the whole site (latest-mix player, press kit, Outside the Box videos, Brand Guidelines)

## Updating the latest mix

The thin player under the header plays one mix: `SPARKBOX_LATEST_MIX` near the bottom of
`index.html`. Paste the new SoundCloud link there. Title and length load from SoundCloud.
- `img/` — photos
- `vid/` — Outside the Box clips (MP4) and their thumbnails
- `brand/` — downloadable logo and icon PNGs, plus `sparkbox-brand-assets.zip`
