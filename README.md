# DJ Sparkbox — sparkboxmusic.com

Official press kit website for DJ Sparkbox. Plain HTML, no build step.
Netlify deploys this repository automatically on every push to `main`.

- `index.html` — the whole site (mix player, press kit, Outside the Box videos, Brand Guidelines)

## Updating the mixes

The mix player reads the `SPARKBOX_MIXES` list near the bottom of `index.html`.
Paste SoundCloud share links there, in the order they should appear. Titles, length,
artwork and dates come from SoundCloud automatically.
- `img/` — photos
- `vid/` — Outside the Box clips (MP4) and their thumbnails
- `brand/` — downloadable logo and icon PNGs, plus `sparkbox-brand-assets.zip`
